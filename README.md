# Homebrew Tap for hanziworksheet-cli (hanziworksheet.com)

Official Homebrew tap for **[hanziworksheet.com](https://hanziworksheet.com)** command-line tools.

## Installation

```bash
brew tap AbigailDavised/hanziworksheet
brew install hanziworksheet-cli
```

## Quick Test

```bash
hanziworksheet-cli --help
```
